# Game Icons

Place game icon images here for each game in The Definitizer.

Required icons:
- `sa2.png` - Sonic Adventure 2
- `heroes.png` - Sonic Heroes
- `riders.png` - Sonic Riders
- `unleashed.png` - Sonic Unleashed
- `unleashed-legacy.png` - Sonic Unleashed (Legacy)
- `forces.png` - Sonic Forces
- `frontiers.png` - Sonic Frontiers

Recommended size: 80x80px or larger (square aspect ratio)
Format: PNG with transparency preferred

If an icon is missing, the app will fall back to `assets/placeholder.png`.
